# 🌾 Smart Market Price Analyzer

An Industry Level Flask-Based Web Application designed to help farmers, traders, and consumers analyze agricultural market prices, monitor daily mandi trends, compare nearby markets, and make smart buy/sell decisions using predictive analytics.

---

## 🚀 Project Overview

Smart Market Price Analyzer is a complete market intelligence platform that provides:

- Real-time agricultural product price monitoring
- Nearby market comparison
- Best buy and best sell market recommendations
- Tomorrow price prediction
- Profit estimation analytics
- Price trend chart generation
- Admin controlled product/market/price management
- Farmer decision support alerts

This project is developed using Python Flask, SQLite, HTML, CSS, and Matplotlib.

## ▶️ How To Run This Project

### Step 1 — Clone Repository

    git clone https://github.com/YOUR_USERNAME/smart-market-price-analyzer.git
    cd smart-market-price-analyzer

### Step 2 — Install Requirements

    pip install -r requirements.txt

### Step 3 — Run Flask Application

    python app.py

### Step 4 — Open Browser

    http://127.0.0.1:5000
